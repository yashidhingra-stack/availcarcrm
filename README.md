# Avail Car CRM

A front-end prototype of a lead-management CRM for car loans. It runs in the browser from a single file, with no build step.

## Run it

Open `index.html` in a browser, or host the folder with GitHub Pages.

## What is in it

- Dashboard with lead charts and a date range
- Lead lists (Audience, Login Business, Hold, Disbursement, Reject) with status filters, search, column chooser, sorting and pagination
- Lead detail page with documents checklist, follow-ups and activity timeline
- Data pages: Leads report, Analysis, Download data
- Segments, Campaign shortcuts, User Management (roles, users, permissions, shifts), Configuration, Settings

## Important

- All data is made-up sample data generated in the browser. Nothing is saved after a refresh.
- There is no login or backend yet. Do not put real customer data in this repository.
- Charts load Chart.js from a CDN, so an internet connection is needed.
